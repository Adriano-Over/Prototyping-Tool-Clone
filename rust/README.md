# Rust migration workspace

This workspace is an incremental migration alongside the current Forma editor. The initial `forma-core` crate validates legacy project envelopes and retains their original JSON, including unknown fields. It also provides a shared undo/redo history for object property and ordered array changes, including atomic batches. This is a foundation, not yet integrated with the editor or a complete set of design commands. Initial typed pages and nodes can be serialized to JSON with hierarchy and geometry validation; unknown object fields on pages, nodes, transforms, and sizes are preserved. Unknown node kinds are retained as strings but have no renderer. Legacy conversion, a complete project format, styling, storage, and the server remain to be implemented.

An experimental project container holds validated pages, identity, revision, unknown project fields, and an optional original legacy envelope. `project_simple_pages` can project simple legacy component trees, including pages with multiple frames, while retaining the entire original envelope. Frame metadata is preserved on each converted frame root but is not interpreted. Multi-frame pages receive a synthetic zero-sized root and a warning. The converter also reports unconverted visual styles and missing dimensions; relative layouts, CSS transforms, and non-pixel geometry are rejected. It is not a complete converter or a finalized on-disk project format.

Variable aliases can be resolved across collections and selected modes, with errors for cycles, missing values, and type mismatches. An initial adapter reads explicitly defined variables from legacy project metadata and retains authored mode order. Legacy untyped `modes` entries, numeric strings, and other unsupported values are not converted; broader parity checks and editor integration remain necessary. The original project JSON remains available unchanged.

From this directory, run `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`, and `cargo test --workspace --locked`. The fixture files are synthetic; the tests compare JSON values, not byte-for-byte serialization.
